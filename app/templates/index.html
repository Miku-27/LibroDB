Philosophy

Why I Built LibroDB

This project started as a way to practice building a complete system end-to-end: authentication, schema design, migrations, deployment, and UI polish — without relying on heavy frameworks to hide complexity.

The goal wasn't scale or growth. It was clarity, correctness, and understanding every moving part.

Core Capabilities

What the system
actually does

Structured Library Model

Uses a structured schema with clearly defined relationships, enabling consistent and predictable data access.

Search & Filtering

Supports searching and filtering by title, author, status, and language through straightforward, predictable query patterns.

Auth & Sessions

Implements authentication using JWTs stored in HTTP-only cookies, with CSRF protection to secure state-changing requests.

Migrations

Manages database schema changes through version-controlled migrations, supporting incremental updates and rollbacks.

Deployment

Deployed on managed infrastructure with a simple, repeatable process that keeps the focus on application behavior.

UI Without Complexity

A minimal UI using Alpine.js for interactivity and Tailwind CSS for styling, designed to support the backend rather than increasing complexity.
