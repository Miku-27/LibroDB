Generate complete API documentation for a Flask backend project in Markdown format. Follow these rules:

1. Project Overview:
- Include project name, short description, base URL, version, authentication method, and global rate limits.

2. Endpoint Summary:
- Create a table with columns: Endpoint, Method, Auth Required, Rate Limit, Description.
- Include all endpoints, for example: /login [POST], /forgot-password [POST], /change-password [POST], /books [GET], /books [POST].

3. Endpoint Details (for each endpoint):
- URL & Method
- Description of functionality
- Authentication required (Yes/No) and method
- Rate Limit (specific if different from global)
- Request Parameters (path, query, body) with required/optional and example JSON
- Response: success response (HTTP code + example JSON) and error responses
- Notes: token expiration, CSRF protection, special headers

4. Error Codes:
- Include common errors with HTTP code, meaning, and example JSON:
  - 400 Bad Request
  - 401 Unauthorized
  - 403 Forbidden
  - 404 Not Found
  - 429 Too Many Requests
  - 500 Internal Server Error

5. Authentication Details:
- Login flow, how JWT token is issued and stored (HttpOnly cookie)
- How to include token in requests
- Token expiration and renewal
- CSRF protection

6. Rate Limiting:
- Global default limits
- Specific limits for sensitive endpoints (login, forgot-password, change-password)
- Specify if limits are per user (JWT) or per IP

7. Examples (Optional but recommended):
- Include example requests for each endpoint:
  - curl commands
  - Python requests snippet
- Include example responses for success and error cases

8. Formatting Guidelines:
- Output must be in Markdown format
- Use headers for sections and subsections
- Use tables for Endpoint Summary and Error Codes
- Use code blocks for JSON, curl commands, Python examples
- Make it readable and developer-friendly so someone can integrate with the API without reading the code

Generate the full documentation with realistic example requests and responses for each endpoint, including all authentication, rate limiting, and error handling.
